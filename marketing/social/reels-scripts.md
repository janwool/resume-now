# Short-Form Video Scripts

Record at 1080 × 1920. Keep UI actions in the center safe area, add burned-in captions, and use a real browser screen recording.

## Script 1 · The template is the editor · 12–15 seconds

**Hook (0–2s):** “This is not a screenshot.”

**Visual:** Open the template gallery and click a real template.

**Proof (2–9s):** Select the name, edit a heading, then scroll to the next page.

**Voiceover:** “Choose the actual template, edit the resume directly, and review every page.”

**CTA (9–15s):** Show the full page and the Start free button.

**On-screen text:** “Choose → edit → preview free”

## Script 2 · Rewrite a weak bullet · 15–18 seconds

**Hook (0–3s):** “Delete ‘responsible for’.”

**Visual:** Highlight “Responsible for weekly reporting.”

**Rewrite (3–12s):** Replace it with “Automated weekly reporting across four regions, cutting preparation time from five hours to forty minutes.”

**Voiceover:** “Use action, context, and a measurable result. Specific beats impressive-sounding.”

**CTA (12–18s):** “Save this formula and edit your resume free.”

## Script 3 · One page or two? · 15 seconds

**Hook (0–3s):** “Your resume does not have to be one page.”

**Visual:** Show a one-page template, then a two-page template.

**Rule (3–11s):** “Use one page when relevant proof fits clearly. Use two when cutting removes strong, role-specific evidence.”

**CTA (11–15s):** Scroll between both pages in the editor. “Preview every page before you export.”

## Production checklist

- Show a product action in the first two seconds.
- Keep each cut purposeful; no decorative intro animation.
- Use one sentence per caption card.
- Do not place essential text at the top 12% or bottom 20% of the frame.
- End on the free value proposition, not the price.
- Export a clean master without platform watermarks for reuse.
